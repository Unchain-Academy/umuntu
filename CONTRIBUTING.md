# Contributing to UMUNTU

The project is in its design phase. The most useful contributions today are comments on
[ARCHITECTURE.md](ARCHITECTURE.md): open an issue.

- Licence: by contributing you agree that your contribution is released under the Apache License 2.0.
- Accessibility: user-facing work must meet WCAG 2.2 AA.
- Generative AI: read [GENAI.md](GENAI.md) before contributing.
- Be kind. *Umuntu ngumuntu ngabantu.*
