# Use of generative AI in UMUNTU

We follow the NLnet Generative AI policy.

## In this repository so far
The first versions of README.md, ARCHITECTURE.md, GENAI.md and CONTRIBUTING.md (October 2026) were drafted with
Claude (Anthropic) from the founder's voice explanations in French, then reviewed and corrected by him.

## Rules for contributions
- Code, tests or documentation produced with a generative AI tool must be marked as such.
- Commits that add generated code name the model (with version) and how it was used, in the commit message.
- Code that is mostly AI-generated ("vibecoding") is not accepted as a milestone deliverable.
- A human contributor reviews and takes responsibility for every change.
